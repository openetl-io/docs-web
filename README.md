# docs-web

The website for OpenETL's documentation. It holds the site, not the pages: those live next to the code they describe, in [openetl](https://github.com/openetl-io/openetl/tree/main/docs) (`docs/`) and in [openetl-connectors](https://github.com/openetl-io/openetl-connectors) (each package's `README.md`). The site is built from them with [Fumadocs](https://fumadocs.dev) and served by Cloudflare Pages.

To change what a page says, change it in its own repository. [AGENTS.md](AGENTS.md) has how the site is put together.

The site isn't built yet: this repository holds what it has to do.
